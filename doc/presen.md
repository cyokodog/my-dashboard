# タスクを雑に管理する TODO アプリ

## 概要

**個人用タスク管理ダッシュボード**

- macOS カレンダーと連携して予定を自動取得
- テキストベースで素早く編集できるタスク管理
- クラウド同期でデバイス間でデータ共有

## 技術スタック

### フロントエンド

- **SvelteKit**
- **TypeScript (strict mode)**
- **Vite**

### バックエンド・インフラ

- **Cloudflare Pages** - エッジでのホスティング
- **Cloudflare Workers** - サーバーレス API
- **Cloudflare Workers KV** - クラウドストレージ（無料枠で運用）
- **Cloudflare Zero Trust Access** - メール認証による個人利用向けアクセス制御

### カレンダー連携

- **iCloud CalDAV（キャルダヴ） API** - 直接 API 経由でイベント取得（1〜3 秒）
- AppleScript も対応（時間かかる） -> Cloudflare のデプロイで問題があるため除去した

### その他

- **marked** - Markdown 記法対応（ノート機能）
- **LocalStorage** - ローカルキャッシュ
- **Last Write Wins (LWW)** - タイムスタンプ比較でデバイス間同期

## 主要機能

### 1. カレンダー連携

```
✅ 直近2週間の予定を自動取得
✅ 本日のイベントを強調表示
✅ 「v」ボタンでタスクに追加
✅ 1日1回の自動更新 + 手動更新機能
```

### 2. タスク管理

```
^買い物
野菜を買う
牛乳を買う

^勉強
JSの勉強をする
```

- `^`で始まる行 = カテゴリ見出し
- `v`で始まる行 = チェック済み
- チェックボックスで ON/OFF 切り替え
- チェック済みを一括削除

### 3. タスクのメモ

- カテゴリ別にメモを管理
- 「+」ボタンで本日のタスクに移動
- 横並び 2 列レイアウト（auto-fit）

### 4. ノート機能

- Markdown 記法対応（GFM）
- 見出し別に管理
- 読み物用（タスク下 + フッター）

## アーキテクチャの特徴

### データ同期戦略

```
LocalStorage ←→ Cloudflare Workers KV
     ↑              ↑
  updatedAt で比較して新しい方を採用（Last Write Wins）
```

- タイムスタンプ比較で新しいデータを優先
- データ全体を置き換える（マージではない）
- 5 秒 debounce で自動保存

### Svelte ストアアーキテクチャ

```
Component (UI)
    ↓
Store (Business Logic)
    ↓
LocalStorage + KV Sync
```

- ビジネスロジックをストアに集約
- コンポーネントはシンプルに

### 認証

- **Cloudflare Zero Trust Access**
  - メールアドレスベースのアクセス制御
  - One-time PIN 認証
  - 24 時間セッション維持
  - アクセスログ記録

## デモポイント

### 1. カレンダー連携

「🔄」ボタンでイベント更新 → 本日のイベントが青色で表示

### 2. タスク編集

「編集」→ テキストエリアで一括編集 →「確定」

### 3. メモからタスクへ移動

メモの「+」ボタン → 本日のタスクに追加

### 4. デバイス間同期

別デバイスでアクセス → データが自動同期されている

## 無料枠内での運用

- KV 書き込み: 1,000 回/日（実際は 10〜20 回/日）
- KV 読み取り: 10 万回/日（実際は 5〜10 回/日）
- ストレージ: 1GB（実際は数十 KB）
